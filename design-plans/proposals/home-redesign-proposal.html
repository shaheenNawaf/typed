Home Screen — Redesign

The current home stacks seven same-weight sections. These directions cut it to two or three visual layers, merge the overlapping lists, and let the icon dock carry creation.

00What makes it feel cluttered today

Seven stacked sections, one hierarchy

Greeting, Pinned, Continue, Today, This Month, Quick Actions, Recent — all with similar visual weight, so nothing leads.

Two lists that overlap

“Continue” and “Recent” show nearly the same pages; Pinned can also repeat them.

Mixed card languages

Outline stat cards, pill rows, chips, and action pills — four component styles on one screen.

Redundant creation paths

New note button + Note quick-action + dock create all do the same thing.
