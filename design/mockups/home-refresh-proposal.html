What changed and why
  • Greeting replaces "Home" — time-aware ("Good morning / afternoon / evening") with a mono date stamp. Warmer, and stops the page title competing with the app bar's "Home".
  • Pinned → quiet chips — pinned items are jump-offs, not content; cards were overweight.
  • Continue → informative rows — each row gains a real status line ("$24.50 · 3 entries", "3 of 8 done") and a mono relative time, so you know why you'd go back.
  • Today's overview → one mono strip — kills the duplicated "6 notes edited" header + metric chip; one tappable line instead of a card with 40px icon chip.
  • NEW: "This month" finance snapshot — finance is a core pillar but home never showed money. Spent / Income in mono, palette-aware colors.
  • Quick actions → compact pill row — 6 giant cards (~340px of vertical space) become one horizontally-scrollable pill row (~44px). "New note" is the accent pill; everything else neutral. Scrollable, so all 6 actions stay available.
  • Accent discipline — accent uses drop from ~10 on screen to 2 (CTA + Note pill), matching the brand rule.
  • Rows over cards — hairline-separated rows for Continue/Recent, per the README product direction.

03Implementation notes

All changes are contained to lib/screens/home_screen.dart builders: _buildHomeIntro, _buildPinnedHome, _buildContinueCard, _buildQuickActions, _buildTodaysOverview (+ a new finance snapshot builder that can reuse the existing period filtering already in the file). No model or storage changes.

  • If you want, "This month" can be tappable → jumps to Finance; and the greeting can include the day's open-task count ("Good afternoon · 3 tasks open").
  • Quick-action pill order is yours to pick; my default: Note, Expense, Income, Task, Meeting, Journal (scrollable).
